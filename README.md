# Builder Calc

A mobile-friendly fractional inch calculator. Enter values on a familiar calculator keypad, add common fractions with shortcut buttons, and see the decimal answer alongside tape marks within ¹⁄₆₄ inch of the exact result.

## Run locally

Open `index.html` in a browser. To try Home Screen installation and offline caching, serve this folder over HTTPS (or localhost); service workers do not run from ordinary `file://` URLs.

## Use on iPhone

Publish these files to a static HTTPS host such as GitHub Pages. Open the site in Safari, tap **Share → Add to Home Screen**. After the first visit, the calculator can work offline.

Fraction shortcuts add ¹⁄₁₆, ⅛, or ¼ inch to the number currently being entered. Tape marks are listed at ¼, ⅛, ¹⁄₁₆, and ¹⁄₃₂ inch resolution, with the difference from the decimal answer shown on each line. Marks farther than ¹⁄₆₄ inch away are hidden.
